threadline remembers every application and freelance thread so you don't have
to. paste an email (or forward it over ses) and it lands in a pile: applied, in
review, selected, rejected, active client. it keeps a timeline, and you can tell
it _"i got the call from acme, i'm in"_ to move a card.

built for the **aws hackathon 2026** on dynamodb, s3 and bedrock converse. the
front end is a calm, daylight-paper opportunity board, so this one is
**low cortisol**.

## VITALS

- **squad** — low cortisol // calm builds
- **built for** — aws hackathon 2026
- **piles** — applied → in review → selected / rejected → active client
- **stack** — node api + dynamodb + s3 + bedrock converse (nova lite)
