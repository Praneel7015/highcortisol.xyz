memora is a support desk run by agents that don't forget. each agent pulls
prior chats from sql and distributed vectors, triages in parallel, and answers
with the context it found. tickets, messages, embeddings and agent traces all
live in one cockroachdb cluster on aws, so the memory survives the agents.

built for the **cockroachdb × aws hackathon**. **high cortisol**: parallel
agents, a live support queue, and a submission window that closed on august 18.
