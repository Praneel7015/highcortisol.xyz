sentinel watches access logs and tells you which ones are wrong, and why. it
profiles every entity's normal behaviour across 43 incremental features, fuses
several detectors into one ranked alert queue, explains each alert, and streams
it all into a soc analyst dashboard over sse.

built in a single day for the **scoping hackathon** (honeywell campus connect).
synthetic data for 1,300 entities and six attack types, 126 passing tests, a
pitch deck, and a live render backend before dark. that's **high cortisol**.
